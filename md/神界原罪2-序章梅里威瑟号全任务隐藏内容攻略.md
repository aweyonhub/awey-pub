## 📚 2. 正式任务基线与收录口径

## 📖 4. 技能、技能书与永久收益速查

### 4.1 技能书购买点

本章**没有可靠的技能书商人**。普通 NPC 即使可打开交易栏，也没有值得围绕其库存规划的固定技能书供应。

### 4.2 固定技能与永久进度

| 内容 | 取得方式 | 是否可错过 | 说明 |
|---|---|---|---|
| **Adrenaline（肾上腺素）** | 【Elf / Corpse Eater】吃 Finn 的 **Chunk of Flesh** | 是 | 永久学会技能；非精灵主角可把尸块留给抵达欢乐堡后招募的 Sebille |
| **Hero 标签进度** | 返舱后尝试救助 Siwan，正确压住伤口 | 是 | 只是 Hero 标签的累计行为之一，不保证当场取得完整标签 |
| **The Collar 长线** | 与 Siwan 完成项圈教学 | 否 | 本章不能解除项圈，欢乐堡继续处理 |

> 【Spirit Vision】序章尚未解锁灵视，船上没有需要以灵视补完的鬼魂事件；这不是遗漏。

## 🎁 5. 唯一装备与跨章物品速查

- 本章**没有经 Definitive Edition 物品表确认的固定 Unique Equipment**。箱子、尸体和容器中的普通武器护甲多为随机生成，不应写成必得唯一装备。
- **【跨章物品：不要卖】Finn's Chunk of Flesh**：若队内当前没人能吃，带到欢乐堡给 Sebille；食用后学会 Adrenaline。
- **床卷（Bedroll）**：不是唯一物品，但会贯穿全游戏；生活区共有多张，至少带走一张并拖入快捷栏。
- 死亡之雾桶可以跨章携带，但取得依赖抢时间、负重构筑或穿墙等特殊技巧，会显著破坏正常关卡体验，不列为必拿。

# 📦 6. 区域一：教学舱、畜栏与监牢支路

## 🎛️ 区域卡

| 项目 | 内容 |
|---|---|
| 推荐进入等级 | Lv1 |
| 推荐完成等级 | Lv1 |
| 主要任务 | Troubled Waters、The Collar 教学阶段 |
| 非日志内容 | 畜栏绵羊、可移动木箱、Cargo Door Key、Hemwar / Rennart、压力板教学 |
| 主要战斗难度 | 正常路线无必打战斗；主动攻击 Rennart 会连带 Hemwar 敌对 |
| 不可逆剧情点 | 暂无；进入下层后仍能回来，直到 Windego 爆发改变船内状态 |
| 建议暂时跳过 | 不要为零经验击杀 Hemwar / Rennart；不必强撬所有高等级箱子 |

## 🧭 实际执行路线

### 6.1 先完成 Siwan 的基础教学

1. 醒来后与 **Magister Siwan** 对话，完成移动、互动和源力项圈说明。
2. 【起源角色专属·Fane / 自建亡灵】房间里的 Grinning Skull 会提醒亡灵遮住面容；找到头盔、兜帽或临时遮挡后立即装备。
3. 不要直接爬梯上楼。先沿起始舱完整绕一圈并开启物品高亮。

> 亡灵裸露骷髅外观会令多数活人恐惧甚至敌对；亡灵也会被普通治疗伤害、被毒素治疗。序章就应建立这一操作习惯。

### 6.2 移开木箱，搜索畜栏与花瓶

1. 南侧通道被木箱挡住；拖开箱子进入动物围栏。
2. **【Pet Pal】绵羊**只有短对白，没有任务、经验或宝藏，但属于本章动物内容。
3. 搜索围栏角落、被其他容器包围的花瓶，取得 **Cargo Door Key**。
4. 用钥匙开邻近货舱门，搜索木桶里的 **Pocket Knife**、食物和杂物。

### 6.3 用箱子压住两块压力板

1. 阅读桌上的 **Stern Letter from Siwan**，它提示可用木箱压压力板。
2. 从前一个房间搬来两只箱子，分别放到门两侧的压力板上。
3. 门开后进入监牢支路；清除或绕开地面的油，避免手持火源引爆自己。

### 6.4 Hemwar 与 Rennart：只看事件，不做无收益屠杀

1. 与牢中的 **Hemwar** 对话，他希望你拉动门边拉杆。
2. 拉杆会惊醒 **Magister Rennart**。如果想看完整和平对白，先存档，再使用说服应对他的两轮质问。
3. 资料没有给出跨版本一致的固定门槛；它会受对话属性与角色差影响。开局有 Persuasion 时选与自身高属性匹配的选项，失败也无需强行重来。
4. Rennart 与 Hemwar 无任务经验；主动杀 Rennart 会令 Hemwar 也攻击你。**推荐：和平离开。**

### 6.5 实验室与基础合成材料

1. 下楼从桌上取得 **Electric Discharge Scroll**。
2. 搜索实验室门附近的木桶拿 **Lockpicks**；若走杀 Rennart 路线，他身上另有门钥匙，但这不是推荐理由。
3. 拿走两瓶 Minor Healing Potion、Mortar and Pestle、Jawless Skull 等材料；颚骨与研钵可合成 Bone Dust。
4. 毒液 / 油桶旁的门可借火焰爆破；通过后拉杆会打开回到起始室的捷径。
5. 所有容器检查完后，爬梯前往下层生活区。

### ✅ 教学舱离开前 Checklist

- [ ] 已与 Siwan 完成项圈和操作教学
- [ ] 【Pet Pal】已和绵羊交谈
- [ ] 已从角落花瓶取得 Cargo Door Key
- [ ] 已读 Stern Letter 并完成双压力板支路
- [ ] 已和平看完 Hemwar / Rennart 事件，或明确接受自己的战斗选择
- [ ] 已取得 Lockpicks、Electric Discharge Scroll、研钵与至少一件武器

> 完成本区后正常仍为 Lv1；Hemwar / Rennart 不给经验，未战斗不代表遗漏。

# 🛏️ 7. 区域二：下层生活区、谋杀案与六名起源角色

## 🎛️ 区域卡

| 项目 | 内容 |
|---|---|
| 推荐进入等级 | Lv1 |
| 推荐完成等级 | Lv1 |
| 主要任务 | Troubled Waters、Death Belowdecks、The Collar、起源主角个人线 |
| 非日志内容 | Finn 尸块、床卷、Greasy Key、土豆泥配方、六名起源角色初见 |
| 主要战斗难度 | 主线爆发前无必打战斗；偷 Finn 尸体被看见会损失态度并可能惹事 |
| 不可逆剧情点 | 进入船尾审讯室并推进 William / Windego 对话后触发爆发 |
| 建议暂时跳过 | 不要袭击 Magister 或起源角色；不必为普通随机装备破坏关系 |

## 🧭 实际执行路线

### 7.1 Siwan → Waters → Finn，按这个顺序走

1. 先搜入口附近的 Mortar and Pestle、Jawless Skull 和容器，再与 Siwan 对话。
2. 她让你到船尾向 **Magister William** 登记；这会推进 `Troubled Waters` 与 `The Collar`。
3. 穿过她身后的门，先听 Magister Cadoc / Marel 谈论命案，再找尸体旁的 **Magister Waters**。
4. 接下 **Death Belowdecks**。无论承诺调查还是态度冷淡，后续真相都由 Windego 事件揭晓。

### 7.2 【Elf / Corpse Eater】取得 Finn 尸块

1. **【先存档】**让 Waters 背过身，进入潜行再搜 Finn 尸体；当面拿取会被视作偷窃并降低她的态度。
2. 取得 **Chunk of Flesh**。
3. 精灵主角可立刻食用；Fane 作为主角时此刻仍有 Mask of the Shapeshifter，也可变成精灵后食用。
4. 吃下后看到 Finn 最后记忆，提前确认凶手是年老妇人，并**永久学会 Adrenaline**。
5. 非精灵自建主角不要丢弃尸块：带到欢乐堡，招募 Sebille 后交给她食用。

> 【容易漏】Finn 尸块是本章最重要的固定收益。Adrenaline 后续可以从技能书学习，但这里能免费学会，并补完谋杀案线索。

### 7.3 先拿床卷和 Greasy Key，再逐个见起源角色

进入大生活区后，至少拿一张 **Bedroll**。完整地图资料显示本层共有三张：一张靠近船首左舷绵羊区，另两张在中央下铺附近。

随后按顺路位置逐一交谈：

| 角色 | 船上位置 / 状态 | 本章要点 |
|---|---|---|
| **Lohse** | 西北侧，给孩子们表演 | 个人线通常到欢乐堡才正式更新；这里先完成初见 |
| **Sebille** | 西南角掷骰子 | 只能对话，不能招募；不要因她的警戒态度开战 |
| **Beast** | 中央桌边 | 矮人水手身份在本章最直观，听完全部提问 |
| **Red Prince** | 中央偏东 | 【起源角色专属】若他是主角，`Redemption` 已进入日志 |
| **Ifan** | 东南角，被 Magister 注视 | 桶 / 地面附近有 **Greasy Key**，开启邻近厨房门 |
| **Fane** | 东北角，伪装成精灵读书 | 会询问你对神祇 / 种族的看法；爆发后面具被 Windego 夺走 |

> 六人此时都不能正式入队。船上对话不会决定后续是否可招募，但能补全初见和起源主角日志背景。

### 7.4 搜厨房和土豆泥配方

1. 在 Ifan 附近打开物品高亮，拿到地面 / 桶边较难看清的 **Greasy Key**。
2. 打开厨房门，拿走食物与基础材料。
3. 阅读墙上的烹饪海报，学习多种土豆泥配方；其中 Mashed Potatoes 可在死亡之雾桶特殊路线中临时增加力量。
4. 与 **Magister Payde** 对话，让他打开通向船尾审讯室的门。

### 7.5 【不可逆】最后再见 William 与 Windego

进入审讯室前检查：Finn 尸块、床卷、六名起源角色、Greasy Key 与厨房是否都处理完。

1. 进入后听完 **Magister William** 审问 **Windego**。
2. Windego 承认杀死 Finn，随后摘除项圈并施放 Source Blast。
3. 玩家与多数囚犯被击昏，Magister 大量死亡，`Death Belowdecks` 随真相揭晓收束。
4. 【Fane 专属】Windego 夺走 Fane 的 Mask of the Shapeshifter；无论 Fane 是主角还是同船 NPC，这都是他之后追查她的起点。

### ✅ 下层生活区爆发前 Checklist

- [ ] Death Belowdecks 已从 Waters 处接取
- [ ] 【Elf / Corpse Eater】Finn 尸块已取得，或已经吃下学会 Adrenaline
- [ ] 至少一张床卷已放入快捷栏
- [ ] 六名起源角色均已完成初见对话
- [ ] Greasy Key、厨房补给和土豆泥配方已取得
- [ ] 确认无遗漏后才进入 William / Windego 审讯室

> 完成本区后正常仍为 Lv1。Windego 爆发是本章第一次明显的地图状态切换。

# 🔥 8. 区域三：灾后受损船舱与死亡之雾舱

## 🎛️ 区域卡

| 项目 | 内容 |
|---|---|
| 推荐进入等级 | Lv1 |
| 推荐完成等级 | Lv1 |
| 主要任务 | Troubled Waters 灾后逃生阶段 |
| 非日志内容 | Confiscated Goods、Murtof / Ricks、复活卷轴、Medwyn 的骷髅钥匙、死亡之雾提示 |
| 主要战斗难度 | 火面、爆炸与说服失败后的两名重伤 Magister |
| 不可逆剧情点 | 打开骷髅门后海怪很快击碎死亡之雾桶；活人进入雾区会立即死亡 |
| 建议暂时跳过 | 默认路线不搬死亡之雾桶，不以穿墙、负重极限或 Flag 技巧破坏后续 |

## 🧭 实际执行路线

### 8.1 醒来后先做第二轮搜刮

1. 从昏迷中醒来后，先搜 **Chest with Confiscated Goods**，补齐武器。
2. 回查 Waters、William 与其他 Magister 的尸体；灾前活着的 NPC 现在有了可搜物品。
3. 【Fane】灾后 Fane 会以骷髅真身出现在中层，因为面具已被夺走；可以补一轮对白，但他不会加入当前队伍。
4. 从船尾楼梯进入受损中层，不要直接冲主甲板。

### 8.2 火场与 Murtof / Ricks

1. 前路被火焰封住，移动 / 攻击附近水桶制造水面灭火。
2. 左侧房间桌上有 Gold Cup；砸开通往船尾房间的脆弱门。
3. 里面的 **Magisters Murtof and Ricks** 会质疑你。
4. **【先存档】门槛资料存在差异**：Guides4Gamers 标作 Persuasion 1+，更新版 GameFAQs 流程记作 Persuade 2。对话还会受所选属性与角色属性差影响，因此无法给出跨版本绝对固定值；准备 Persuasion 1、选最高属性对应选项并提前存档最稳妥。
5. 说服成功便和平通过；失败则与两名已重伤 Magister 战斗。
6. 无论分支如何，搜他们房间的桌子，取得 **Resurrection Scroll**。

### 8.3 骷髅门与死亡之雾

1. 向船首前进，记住画有骷髅的门。
2. 在附近 **Magister Priest Medwyn** 的尸体上取得 **Skull-Marked Key**。
3. 默认路线先远离门口、分开队伍再开门；海怪会击碎里面的死亡之雾桶，毒雾迅速扩散。
4. 活人角色接触 Deathfog 会立即死亡；亡灵免疫死亡之雾本身，但仍会受其他伤害与地形影响。
5. 门内没有必须冒死取得的 Unique。看到事件、更新危险信息后立即撤回即可。

### ⚠️ 最大经验 / 特殊玩法：搬走死亡之雾桶

社区实测与新版流程确认可以用亡灵、Haste、力量食物和精准操作抢到至少一桶；新版流程给出的常见安全准备是 **13 Strength + Haste**，Mashed Potatoes 可临时提供力量。另有撬锁延长触发时间、穿墙、念力搬运等做法。

这条路线的问题是：

- 桶极重，正常 Lv1 队伍几乎无法携带；
- Deathfog 能秒杀大量活人，严重破坏欢乐堡与后续遭遇；
- 穿墙 / 卡触发属于明显的特殊机制玩法；
- 它不提供独有剧情，也不是“全内容”周目的必需品。

**推荐：看过舱室事件即可，不拿桶。**

### ✅ 受损船舱离开前 Checklist

- [ ] Confiscated Goods 与灾后新尸体已二次搜刮
- [ ] 已补看 Fane 骷髅真身状态
- [ ] Murtof / Ricks 已和平说服，或已接受说服失败战斗
- [ ] 房间桌上的 Resurrection Scroll 已拿
- [ ] Medwyn 的 Skull-Marked Key 已取得
- [ ] 死亡之雾事件已触发，且全队安全撤离

> 完成本区后通常仍为 Lv1；是否搬死亡之雾桶不计入正常完整度。

# 🌊 9. 区域四：主甲板、救生艇与返舱救援

## 🎛️ 区域卡

| 项目 | 内容 |
|---|---|
| 推荐进入等级 | Lv1 |
| 推荐完成等级 | Lv1–2 |
| 主要任务 | Troubled Waters 最终阶段 |
| 非日志内容 | Captain Kalwyn 尸体、救生艇三名孩童、五名起源角色返舱战、Siwan 的 Hero 进度 |
| 主要战斗难度 | 两只 Viscous Voidling；返舱后数只 Void Hatchling |
| 不可逆剧情点 | 第一次救生艇对话可直接逃；帮助 Siwan 到最后一步会立即进入沉船结局 |
| 建议暂时跳过 | 无；但必须先救起源角色，再最后去 Siwan |

## 🧭 实际执行路线

### 9.1 清理主甲板

1. 登上主甲板会遭遇 **2 只 Viscous Voidling**。它们无护甲、生命不高，集中击杀即可。
2. 避开火面，用水桶开路；不要让角色站在爆炸桶附近结束回合。
3. 到舵轮附近搜索 **Captain Kalwyn** 尸体与沿路容器。
4. 绕到另一侧找到救生艇中的 **Paulie、Trice、Gil**。

### 9.2 【必做】第一次点救生艇，选择回去救人

与救生艇互动时，孩子会提醒下层还有幸存者：

| 选择 | 结果 |
|---|---|
| **立即逃走** | 序章结束；跳过返舱虚空幼虫、起源角色救援与 Siwan 的 Hero 进度 |
| **回去救人** | 开启完整英雄路线；仍可稍后离船 |

**推荐：回去救人。**

### 9.3 先救五名起源角色

1. 返回下层生活区，会看到 **Ifan、Lohse、Sebille、Beast、Red Prince** 正在与 Void Hatchlings 作战。
2. 优先集火已经受伤的幼虫，利用门口形成窄道；起源角色会协助战斗。
3. 清场后幸存者从附近梯子离开。
4. Fane 不在这组五人战斗中；他在灾后已以骷髅形态转移，未出现在此处不算遗漏。

### 9.4 【不可逆】最后才尝试救 Siwan

确保所有 Checklist 都已完成，再去找重伤的 Siwan：

1. 选择用布压住伤口并持续施压的救助选项。
2. 这是取得 **Hero 标签** 的累计行为之一。
3. 当你尝试扶她起身时，海怪摧毁船体；Siwan 无法在正常剧情中救活。
4. 玩家被冲上海滩，序章结束。

> 如果想让自己而非队友获得 Hero 进度，务必由目标角色发起这段对话。

### ✅ 主甲板与救援 Checklist

- [ ] 两只 Viscous Voidling 已清理，Captain Kalwyn 尸体已搜
- [ ] 第一次救生艇互动选择了“回去救人”
- [ ] 五名起源角色的 Void Hatchlings 战斗已完成
- [ ] 所有其他搜刮都完成后，最后才与 Siwan 互动
- [ ] 已正确压住 Siwan 伤口，取得 Hero 标签进度

> 正常路线离船时多半仍为 Lv1，并会在欢乐堡海滩初期升到 Lv2；若通过和平与必要战斗已拿到全部正常经验，无需屠杀补等级。

# ⚖️ 10. 关键分支结果总表

## 10.1 Hemwar / Rennart

### 路线 A：和平处理（推荐）

- 两人暂时存活；
- 能看完监牢教学对白；
- 不损失任何任务经验，因为击杀本身也不给经验；
- 符合剧情完整路线。

### 路线 B：主动击杀

- 攻击 Rennart 后 Hemwar 也会敌对；
- 没有任务 XP 优势，只有少量普通搜刮；
- 不影响主线，但属于无收益屠杀。

## 10.2 Murtof / Ricks

### 路线 A：说服（推荐）

- 二人存活到海难；
- 正常推进 `Troubled Waters`；
- 不必为重伤目标额外战斗。

### 路线 B：说服失败后战斗

- 二人死亡；
- 主线仍可继续，复活卷轴仍能取得；
- 适合作为失败后的正常补救，不必读档强求。

## 10.3 救生艇

### 路线 A：回去救人（默认推荐）

- 补完五名起源角色返舱战；
- 能尝试救 Siwan 并累计 Hero 进度；
- 剧情与正常经验最完整。

### 路线 B：立即逃走

- 序章提前结束；
- 起源角色后续一般仍会出现在欢乐堡，但本章救援内容与收益被跳过；
- 不适合全内容路线。

## 10.4 Siwan

无论如何都不能把 Siwan 活着带到欢乐堡。**尝试救她与放弃她属于叙事和标签进度差异，不存在真正“救活”分支。**

# 👑 11. 六名起源角色本章核对

| 角色 | 本章必须检查 | 顺序错误会损失什么 |
|---|---|---|
| Ifan | 初见对白；返舱五人战 | 只损失本章对白与战斗参与，不锁欢乐堡招募 |
| Lohse | 给孩童表演时交谈；返舱五人战 | `The Thing Inside` 通常到欢乐堡才正式更新 |
| Sebille | 西南角掷骰处交谈；返舱五人战 | 非精灵主角可在欢乐堡招募她后让她吃 Finn 尸块 |
| Red Prince | 初见；若为主角确认 Redemption 日志；返舱五人战 | 不影响欢乐堡招募，但少一次角色印象对白 |
| Beast | 中央桌边初见；返舱五人战 | 不影响欢乐堡招募 |
| Fane | 伪装状态初见；爆发后看骷髅状态 | 面具被 Windego 夺走是既定事件，无法在船上阻止 |

> 序章中击倒或故意杀死起源角色通常不会可靠地永久删除其欢乐堡版本，但这是状态重载 / 特殊玩法范畴，可能产生异常对白，不应作为最大经验默认方案。

# 🧪 12. 最大经验 / 特殊玩法说明

极限路线常见做法包括：先说服再击杀 Murtof / Ricks、挑起全船战斗、袭击昏迷起源角色、搬运死亡之雾桶，甚至利用穿墙或触发时间差。

它们的问题是：

- 多数中立 NPC 只给很少经验或完全不给经验；
- 容易让教学事件、对白和态度状态变得混乱；
- 屠杀起源角色后仍在下一地图刷新属于地图状态重载，不是自然剧情收益；
- 死亡之雾桶会让第一章大量正常战斗失去意义。

**默认完整路线只取和平 / 任务 / 必要战斗经验。**如果目标纯粹是挑战“在船上升 Lv2”，请另存特殊档，不要覆盖剧情主档。
