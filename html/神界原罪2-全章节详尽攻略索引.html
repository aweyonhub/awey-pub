🚢3. 序章｜梅里威瑟号

🧭推荐路线

教学舱 / 畜栏 → Finn 谋杀案与六起源初见 → Windego 爆发后二次搜刮 → 主甲板 → 第一次拒绝登艇 → 返舱救人 → 离船。

🔹本章重点

  • 【Elf / Corpse Eater】Finn 的 Chunk of Flesh 可免费学会 Adrenaline；
  • 正常路线没有固定 Unique Equipment，也没有可靠技能书商人；
  • 爆发前和爆发后是两套船舱状态，必须二次搜索；
  • 救生艇第一次出现时选择回去救人，才能看到完整起源角色救援和 Siwan 收束；
  • 死亡之雾桶属于高风险特殊路线，不是 100% Checklist 的必拿项。

🏰4. 第一章｜欢乐堡与死神之眼岛

🧭推荐路线

海滩招募与起源初见 → 城门 Atusa → 欢乐堡集市 / 洞穴 / 竞技场 → 地下监牢与城堡逃生 → 空洞沼泽低危区 → Amadia 避难所 → Braccus 遗迹群 → 冬龙与 Shriekers → 港口 Alexander → 离岛总检查。

🔹本章重点

  • 先稳定队伍、买齐十系技能书，再选择逃出 Fort Joy 的方式；
  • Griff、Stingtail、Sebille、Red Prince、Amyro 共享 NPC，必须按起源角色顺序对话；
  • 逃出城堡不等于离开整座岛，仍可回欢乐堡补任务；
  • Tyrant、Captain、Devourer、Contamination 四条装备长线从第一章开始；
  • Purging Wand、Braccus 宝库、Slane 与 Shriekers 决定港口路线；
  • 真正锁岛的是向 Malady 确认启航，不是第一次越狱。

⛵5. 航船间章｜复仇女神号

🧭推荐路线

主甲板限时采购 → 重组永久四人队 → Alexander 取 Strange Gem → Fortitude 开 Dallis 舱 → 秘密底舱 → 唤醒 Figurehead → 守 Malady 五回合 → 回音大厅 Bless 神祇 → 死神海岸 / 无名岛 / 阿克斯持续回访。

🔹本章重点

  • Simone、Exter、Samadel 等临时技能商人会在袭击后消失；
  • Red / Blue Teleporter Pyramid、Steam Lance、Shackles of Pain 与 Knaap 都可永久错过；
  • 船战胜利条件是保护 Malady，不要求击杀 Dallis；逼退 Dallis 另有条件独占装备；
  • 第一次回音大厅结束后，未进入四人队的起源角色永久不可招募；
  • 魔镜、储物箱、雇佣兵、Tarquin、Almira、Corbin、Jahan 与 Possessed Child 的跨章位置统一在本篇追踪；
  • 无名岛离开前卖给 Corbin 的特定装备，可在阿克斯按 Lv18 库存重新购回。

🌊6. 第二章｜死神海岸

🧭17 区等级路线

船上整备 → 登陆海岸 / 锡瓦 → 浮木镇地表 → 地下酒馆 → 东桥农田 → 西郊 → Mordus 洞穴 → Stonegarden → 北农田 → Cloisterwood → Paladin Bridgehead → Blackpits 地表 → 矿洞 → Paradise Downs → 精灵营地 / 锯木厂 → 高级 Boss → Bloodmoon Island → 离岛扫尾。

🔹本章重点

  • 漂流之森四名核心商人覆盖十系技能书，Lv9、13、16 分三次回购；
  • Siva 三次仪式依次提供 Spirit Vision、Source Vampirism 与无名岛位置；
  • 七名 Source 导师不要求全部击杀或互斥，默认优先保留 NPC 与 Pet Pal；
  • Lohar / Julian、Ryker / Almira、Jahan / Advocate 都有兼容顺序；
  • Blackpits、Stonegarden、锯木厂和 Bloodmoon Island 是任务与唯一装备最密集区域；
  • The Elven Seer 与 Vengeance for the Fallen 由第一章 Saheila 生死决定，正常互斥；
  • 离开前必须完成四遗物、Anathema 两件、Voidwoken Fish Exchange Scroll、Corbin 与六起源角色检查。

🏝️7. 第三章｜无名岛

🧭10 区等级路线

船上准备 → Amadia 云端神殿 → 古代洞穴 / 蜥蜴神殿 → Duna / 黑环 / Rhalic → Delorus / Vrogir → Xantezza → 精灵神殿 → 苍白人洞穴 / Lunar Gate → Academy → Arena of the One。

🔹本章重点

  • 先亲自祈祷七座祭坛，再从 Alexander / Sallow Man 取得整套答案；
  • Red Prince 必须先与 Shadow Prince 交谈，再让 Sebille 完成复仇；
  • Black Ring 商人和精灵神殿商人合计覆盖十系技能书，阵营敌对前先买；
  • Alexander、Sallow Man、Gareth、Delorus 的最终状态存在正常互斥；
  • Academy 六名教师提供全队唯一的永久 +5 / -5 交换；
  • Swornbreaker 柄、刃、Ancient Stone Tablet 与交付对象需要提前规划；
  • Key of the One、Isbeil's Missive、Windego Letter 和吞噬者护腿都要带入后章；
  • 学院后门会提前改变多项任务状态，不作为默认入口。

🏙️8. 第四章｜阿克斯与终局

🧭14 区等级路线

坠毁点 / 回音大厅 → 朝圣营与 Iris → 港口 → 城门 / 市集 → 兵营 / 监狱 → 学校 / 教堂 → 婚礼 / Sanguinia → 下水道 Karon / 污染实验室 → Tomorrah / Isbeil / Justinia → Kemm 庄园 / Vault / Arhu → 领事馆 / Sadha / Devourer → Black House / Doctor → Loic 与全城扫尾 → Sanders / Path of Blood / Crypt。

🔹本章重点

  • Deathfog 默认排入海中；排进 Arx 会杀死市民、关闭任务并破坏 Ifan 路线；
  • Tarquin 只有在兵营读 Dallis' Private Journal 后才交 Anathema；
  • City Square 与教堂东南商人覆盖十系终阶技能书；
  • Faithful 九件、Kemm 两幅机关画、Swornbreaker、Arhu 生存都容易漏；
  • Beast / Justinia、Red Prince / Sadha、Lohse / Doctor 三条大型队友线必须在墓穴前完成；
  • 污染套和吞噬者套在本章完成最终形态；
  • Sanders 的满充 Source Amulet + Scroll of Atonement 是正常角色通过 Path of Blood 的官方路线；
  • Crypt 三元素管道后，Room of Death 正确拉杆依次拼成 POWER。

⚠️11. 六个永久节点

  1. 梅里威瑟号救生艇：序章永久结束。
  2. 首次回音大厅结算：复仇女神号永久四人队锁定。
  3. Malady 离开死神之眼岛：欢乐堡与整座第一岛永久关闭。
  4. Malady 离开死神海岸：漂流之森、黑井、血月岛永久关闭。
  5. Eternal Arbiter → Arena of the One：无名岛与正常回船采购永久关闭。
  6. 打开 Lucian 墓穴并进入最终对峙：阿克斯任务和商店不能再补。

每个节点前都建立独立永久存档，不要只依赖自动存档与快速存档。
